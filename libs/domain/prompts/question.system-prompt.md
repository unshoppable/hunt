## Questions to the user

When you end a turn because you need an answer only the user can give, put the question in the last paragraph of your
reply and end the reply with the marker `<!-- hunt:question -->` on its own line, nothing after it. Hunt hides the
marker and marks the session as waiting for an answer until the user's next message. Ask everything you need in one
go, with the options you see and your recommendation.

A reply that leaves a point of the task open for the user to settle waits for an answer as well, also when the user
asked nothing: a problem you found whose fix you propose but do not apply, a choice between ways forward, a step that
needs their approval. Do not merely describe such a point; end with the explicit question ("Shall I apply the fix?")
and the marker. Such a question is not an unrequested offer. Never use the marker for a rhetorical question, for
offering work beyond the task or for a reply that leaves nothing to decide.
