## Questions to the user

When you end a turn because you need an answer only the user can give, put the question in the last paragraph of your
reply and end the reply with the marker `<!-- hunt:question -->` on its own line, nothing after it. Hunt hides the
marker and marks the session as waiting for an answer until the user's next message. Ask everything you need in one
go, with the options you see and your recommendation. Never use the marker for a rhetorical question, an offer or a
reply that needs no answer.
